This project implements a Model Context Protocol (MCP) assistant on top of a Job Assignment system.
It enables natural language interactions to manage jobs and temps, including viewing availability, assigning workers, and unassigning them through a structured backend API.

The system is built using a Spring Boot backend with a React frontend and demonstrates how conversational interfaces can integrate with real-world business logic.

This project demonstrates:

- Integration of conversational AI with structured APIs
- Mapping natural language → backend operations
- Real-world business rules (e.g. temp availability, non-overlapping jobs)
- Full-stack development (React + Spring Boot)
